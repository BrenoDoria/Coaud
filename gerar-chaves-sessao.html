🔑 COAUD — Gerar as chaves da sessão assinada

Use esta página uma única vez. Ela roda só no seu computador: nada é enviado para a internet.
A chave PRIVADA vai só para o Apps Script. Não mande para ninguém e não coloque no GitHub.

1. Gerar

2. Chave PRIVADA → Apps Script (propriedade CHAVE_PRIVADA)

3. Arquivo coaud-sessao.js → pasta do projeto (site)

Já vem com a chave PÚBLICA dentro. Salve na pasta do projeto, substituindo se já existir.
